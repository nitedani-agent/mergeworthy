# Docs-reader brief (the docs reader of a docs change)

Standards: `~/.mergeworthy/current/skills/writing/SKILL.md` §Machine-written. Include `delegate/agent.md`.

The reader gets only the rendered page text and two sibling pages, not the diff or your reasons (`docs` step 4).

```
Read <rendered page text file> and two sibling pages, <path> and <path>. Nothing else.
(a) Can you do the task from this page alone, for each setup it claims to cover (each server, framework or runtime)? Where do you get stuck?
(b) Which sentences read unlike the siblings, and why?
Write <work folder>/<name>.docs-read.md.
Final message: (a) yes or where you got stuck; (b) the count of sentences.
```
